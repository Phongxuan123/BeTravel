## Controlled Goods

Controlled goods require proper authorisation (advance notification, licence or certificate approval) from **Competent Authorities (CA)** before they may be imported to Singapore. You are advised to check if the goods are controlled using the description of the goods, Harmonised System (HS) code or CA product code via the [HS/CA Product Code Checker ↗ (opens in new tab)](https://hscodechecker.gobusiness.gov.sg/). If the item is subject to control, you may check directly with the respective CAs on their licensing requirements. You may download the list of CAs' contact information via the HS/CA Product Code Checker.
