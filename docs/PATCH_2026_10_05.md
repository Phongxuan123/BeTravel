# BeTravel — hướng dẫn áp dụng bản vá 05/10/2026

## Áp dụng

1. Sao lưu dự án hiện tại. Giải nén `BeTravel_changed_files.zip` **ngay tại thư mục gốc BeTravel**, nơi có `backend/`, `mobile/`, `admin/`, `contracts/`, `docs/`. Cho phép ghi đè các file tương ứng. Không giải nén vào riêng backend/mobile và không xóa các file còn lại.
2. Bản vá không chứa `.env`, mật khẩu, `node_modules`, `.git`, build output hoặc bản sao toàn bộ dự án. Giữ cấu hình hiện tại của bạn.
3. Trong mỗi thư mục `backend`, `admin`, `mobile`, chạy `npm ci`. Đặc biệt mobile phải chạy postinstall bình thường để áp bản vá `query-string` có sẵn của dự án; không dùng `--ignore-scripts`.
4. Database dùng **replica set** để hỗ trợ transaction (Atlas hỗ trợ). Nếu dùng Mongo local dạng standalone, cần chuyển sang replica set trước. Chưa chạy bất kỳ lệnh seed/migrate nào lên Atlas thật.
5. Trong backend chạy `node scripts/check-content-indexes.js`: đây là kiểm tra read-only, chỉ báo khả năng transaction và sự tồn tại của partial unique index. Cả hai phải true trước khi triển khai. Script không tạo index hoặc sửa dữ liệu.
6. Cập nhật backend, admin và mobile trong **cùng đợt** vì API tiến độ incident đổi từ số thứ tự sang ID bước. Bản mobile cũ gửi số sẽ nhận lỗi validation; không trộn phiên bản cũ/mới.

Chạy phát triển: backend `npm run dev`; admin `npm run dev`; mobile `npm start`, sau đó quét QR bằng Expo Go phù hợp phiên bản dự án. `EXPO_PUBLIC_API_URL` phải trỏ đến backend mà thiết bị truy cập được; điện thoại không dùng localhost của máy tính.

## Bằng chứng kiểm tra

Kiểm tra trong môi trường Linux, Node 24.19.0, MongoDB tạm replica set và provider mock; không kết nối Atlas/AI/SMTP thật.

- Backend: lint đạt; bộ test toàn phần cuối **262/262**, không skip/todo. Golden 26 câu nằm trong bộ này.
- Mobile: lint + TypeScript đạt; Jest **160/160**; `expo export --platform android` thành công.
- Admin: lint đạt; build production thành công; Vitest **18/18**.
- Hồi quy mới: country aliases và pipeline không gọi LLM; SOS verified-only; publish rollback nếu tạo queue lỗi; legacy progress giữ đúng tick khi reorder và bỏ tick của bước đã xóa.

Lệnh chạy lại:

```sh
# backend/
npm run lint
npm test

# mobile/
npm run lint
npm run typecheck
npm test -- --runInBand
npx expo export --platform android --output-dir /tmp/betravel-export

# admin/
npm run lint
npm run build
npm test
```

Bundle Android là kiểm tra đóng gói JavaScript/assets, **không phải APK đã ký**. Chưa kiểm chứng GPS, gọi điện, Maps, bàn phím iOS, chia sẻ Zalo/SMS, first-install offline trên điện thoại thật; chưa thử provider AI/Atlas Search/SMTP production. Kết quả tự động không chứng minh ứng dụng không còn mọi lỗi.
